# Scope: Milestone 1: Build Revert & Verification Foundation

## Architecture
- Target directory: `dandy-gb/`
- Build file: `dandy-gb/Makefile`
- Core game engine entry point: `src/dandy_core.c` (and/or relevant GameBoy wrappers)
- Verification pipeline: `tools/verify_compression.py`
- Objective: Revert the multi-bank ROM configuration back to a flat 32KB ROM (no-MBC).

## Milestones
| # | Name | Scope | Dependencies | Status |
|---|------|-------|-------------|--------|
| 1 | Investigate & Plan | Analyze dandy-gb/Makefile, src/dandy_core.c, and map files. | none | DONE |
| 2 | Revert ROM Configuration | Modify dandy-gb/Makefile and src/dandy_core.c to remove bank-switching. | M1 | DONE |
| 3 | Verification Tooling | Create tools/verify_compression.py checking ROM size, map segments, and round-trip skeleton. | M2 | DONE |
| 4 | Verification & Audit | Run reviews, challengers, and forensic auditor. | M3 | DONE |

## Interface Contracts
### ROM Build Target
- Output path: `bin/dandy.gb`
- Size: Exactly 32,768 bytes (no-MBC, flat 32KB).
- Map file: `dandy.map` generated by the link stage.
