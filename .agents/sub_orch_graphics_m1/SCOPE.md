# Scope: Milestone 1 - Exploration & Verification Foundation

## Architecture
This milestone establishes the data extraction and visual verification baseline for the graphics conversion pipeline.
1. **Source Sprite Sheet**: Extracted from `dandy-js/strike.js` (base64 encoded PNG).
2. **GameBoy Sprite Sheet Representation**: Stored in `dandy-gb/src/tiles.c` as GBDK 2bpp formatted byte arrays.
3. **Verification**:
   - `strike_original.png` (256x16 pixels) is the original reference.
   - `verify_graphics.py` decodes the 2bpp format from `tiles.c` back into pixels, upscales them 8x using nearest-neighbor, and aligns them next to 8x upscaled versions of the original 16x16 tiles from `strike_original.png`.
   - `graphics_audit.png` is the visual comparison sheet generated by the verification script.
   - A clean GBDK build verifies that any existing/modified assets compile correctly in the GameBoy C engine.

## Interface Contracts
- **Input GBDK tiles format**: 2bpp format (2 bytes per row of 8 pixels, 16 bytes per 8x8 tile, 4 tiles per 16x16 sprite).
- **Comparison Image Layout**: 8x upscaled side-by-side comparison (Original tile next to compiled/decoded tile).
