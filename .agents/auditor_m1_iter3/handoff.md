- **Adversarial Robustness**: **FAIL** (5 vulnerabilities documented) — The simplified regex-based parsers fail under adversarial comments, template strings, or invalid hex formats.

### Robustness Vulnerabilities Found
1. **JS Extractor Template Literal Vulnerability**: The extractor does not strip template literals (backticks), allowing dummy assignments inside template literals to override active assignments.
2. **JS Extractor Comment Swallowing**: Certain division/multiplication patterns (e.g. `/a/*b;`) confuse the comment stripper, causing it to swallow subsequent code.
3. **C Parser Comment Order Bug**: The C parser strips single-line comments `//` before block comments `/*`, which destroys closing block comment marks if they look like `// */`. This leaves block comments open and causes the parser to match commented-out arrays.
4. **C Parser Silent Hex Validation Failure**: The parser extracts invalid hex strings (like `0xGG` or `0x12G`) by matching the leading digits (e.g. `0` or `0x12`) and silently ignoring the invalid characters, leading to corrupted tile data instead of an error.
