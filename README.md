This is a collection of different implementations of a simple 2D dungeon
game, "Dandy Dungeon". I wrote the original version in [6502 assembly for
the Atari 800](https://github.com/jackpal/Dandy-Dungeon/tree/main/dandy-atari-8-bit).

I've written versions in numerous languages since then:

+ [Atari 8-bit Assembly](dandy-atari-8-bit/)
+ [Clojure](dandy-clojure/) / [ClojureScript](dandy-clojurescript/)
+ [CoffeeScript](dandy-coffee/)
+ [C++ (for Xbox 360 and Windows)](dandy-cpp/)
+ [C# / XNA](dandy-csharp/)
+ [Dart](dandy-dart/)
+ [F#](dandy-fsharp/)
+ [Game Boy (Z80 / RGBDS)](dandy-gb/)
+ [Haskell](dandy-haskell/)
+ [iOS (Objective-C & Swift)](dandy-ios/)
+ [JavaScript](dandy-js/)
+ [LispyScript](dandy-lispyscript/)
+ [Python](dandy-py/)
+ [Rust (WASM Web & Serverless 4-Player P2P Rollback Co-op)](dandy-rust/)
+ [Swift](dandy-swift/)
+ [TypeScript](dandy-ts/)

It is a bit obsessive-compulsive to keep revisiting the same program,
but it helps me get a feel for a new programming language. Perhaps it might
be useful for other people wishing to compare and contrast different programming
language styles.
